¿De dónde sale la integral?

Una guía de repaso, paso a paso y sin prisa, para entender qué es una integral, por qué existe y cómo se calculan las más directas.

Área bajo una curva→ Rectángulos→ Sumas de Riemann→ Límite→ Integral→ Reglas directas

Conocimientos previos

Antes de empezar, aquí están las herramientas que vas a usar. Abre solo las que quieras repasar; si ya las dominas, puedes saltar a la sección 1.

Funciones: evaluar y graficar

Una función es como una máquina: le metes un número x y te devuelve otro número f(x).

Ejemplo con f(x) = x² + 1. Para evaluar en x = 3:

  1. Cambiamos cada x por 3:
    f(3) = 3² + 1
  2. Calculamos la potencia: 3² = 3 · 3 = 9
    f(3) = 9 + 1
  3. Sumamos:
    f(3) = 10

En la gráfica, f(x) es la altura de la curva en el punto x. Esta idea (valor de la función = altura) es clave para todo lo que sigue.

Áreas de figuras básicas

Rectángulo

Área = base × altura

Triángulo

Área = base × altura2

Trapecio

Área = (B + b)2 × h

El rectángulo es el protagonista de toda esta guía: es la figura cuya área es más fácil de calcular.

Factorización y productos notables

A veces una expresión parece difícil de integrar, pero al factorizar (o al desarrollar) se vuelve sencilla.

Factor común

3x² + 6x = 3x(x + 2)

Diferencia de cuadrados

a² − b² = (a − b)(a + b)   →   x² − 9 = (x − 3)(x + 3)

Trinomio x² + bx + c

Buscamos dos números que multiplicados den c y sumados den b.

  1. Para x² + 5x + 6 buscamos dos números que multiplicados den 6 y sumados den 5.
  2. Probamos: 2 · 3 = 6 y 2 + 3 = 5. ¡Funcionan!
  3. Escribimos:
    x² + 5x + 6 = (x + 2)(x + 3)

Cuadrado de un binomio (desarrollar)

(a + b)² = a² + 2ab + b²   →   (x + 1)² = x² + 2x + 1

Suma y diferencia de cubos

a³ − b³ = (a − b)(a² + ab + b²)     a³ + b³ = (a + b)(a² − ab + b²)
⚠ Ojo
Para integrar, el objetivo es convertir productos y divisiones en sumas y restas de potencias, porque esas sí tienen regla directa.
Notación sumatoria (Σ)

La letra griega Σ (sigma mayúscula) significa "suma todo esto". Es una forma corta de escribir sumas largas.

4Σi = 1 i = 1 + 2 + 3 + 4 = 10

Se lee: "suma de i, desde i = 1 hasta 4". La i es un contador que va tomando los valores 1, 2, 3, 4.

Otro ejemplo, paso a paso:

  1. Queremos calcular 3Σi = 1 i².
  2. Reemplazamos i por 1, luego por 2, luego por 3:
    1² + 2² + 3²
  3. Calculamos cada potencia:
    1 + 4 + 9
  4. Sumamos:
    14
💡 Analogía
Σ es como el total de una factura del súper: cada línea es un producto, y Σ dice "suma todas las líneas".

Límites al infinito

La idea más importante: si dividimos un número fijo entre algo que crece sin parar, el resultado se acerca a cero.

limn→∞ 1n = 0

Piensa en repartir una pizza entre 10, luego 1 000, luego 1 000 000 de personas: a cada quien le toca casi nada.

Ejemplo que aparecerá más adelante, paso a paso:

  1. Queremos limn→∞ 2n² + 3n + 16n².
  2. Separamos la fracción en tres partes (cada término de arriba entre el de abajo):
    2n²6n² + 3n6n² + 16n²
  3. Simplificamos cada una:
    13 + 12n + 16n²
  4. Cuando n → ∞, las dos últimas fracciones tienen n abajo, así que se van a 0:
    13 + 0 + 0 = 13

La gran pregunta: el área bajo una curva

Todo empieza con una pregunta que parece sencilla.

Calcular el área de un rectángulo o de un triángulo es fácil: tenemos fórmulas. Pero, ¿qué pasa si la figura tiene un borde curvo?

Imagina la gráfica de f(x) = x² entre x = 0 y x = 1. La región que queda entre la curva y el eje x tiene tres lados rectos (el piso, la pared izquierda y la derecha) y un "techo" curvo. No existe una fórmula de geometría básica para eso.

💡 Analogía
Imagina que quieres pintar una pared que, en lugar de terminar en línea recta arriba, termina en forma de colina (como debajo de unas gradas o un techo curvo). Para comprar la pintura necesitas saber cuántos metros cuadrados tiene. ¿Cómo los calculas si el borde es curvo?

¿Y por qué importa tanto?

Porque "área bajo una curva" aparece en muchísimas situaciones reales, no solo en dibujos:

🚗 Distancia recorrida

Si la velocidad es constante, distancia = velocidad × tiempo (un rectángulo). Si la velocidad cambia, la distancia es el área bajo la gráfica de velocidad.

💧 Agua acumulada

Si sabes cuánta agua entra por minuto a un tanque (y cambia con el tiempo), el total acumulado es un área bajo una curva.

⚡ Consumo eléctrico

El recibo de luz mide energía: el área bajo la curva de potencia que usó tu casa a lo largo del mes.

★ Idea central
La integral nace para responder: ¿cuánto se acumula algo cuando la cantidad va cambiando? Geométricamente, eso es el área bajo una curva.

La idea genial: usar rectángulos

Si no sabemos medir figuras curvas, las aproximamos con figuras que sí sabemos medir.

La estrategia que usaron los matemáticos fue esta:

  1. Dividir el intervalo (el "piso") en pedacitos del mismo ancho.
  2. Sobre cada pedacito, dibujar un rectángulo cuya altura sea la altura de la curva en algún punto de ese pedacito.
  3. Sumar las áreas de todos los rectángulos (base × altura de cada uno).
  4. Ese total es una aproximación del área real. Con pocos rectángulos sobra o falta un poco de área en cada uno.
  5. Si usamos rectángulos más delgados (más cantidad), el error se hace cada vez más pequeño.
💡 Analogía: los píxeles
Una foto en la pantalla está hecha de cuadraditos (píxeles). Con pocos píxeles, un círculo se ve "escalonado". Con millones de píxeles, el círculo se ve perfectamente redondo. Con los rectángulos pasa lo mismo: entre más delgados y más cantidad, mejor se parece la suma al área real.

¿Dónde medimos la altura de cada rectángulo?

Hay varias opciones y todas son válidas:

Extremo izquierdo

La altura se toma en el borde izquierdo de cada pedacito.

Extremo derecho

La altura se toma en el borde derecho de cada pedacito.

Punto medio

La altura se toma justo en el centro. Suele dar una mejor aproximación.

Con pocos rectángulos, cada opción da un número distinto. Pero lo sorprendente es que, cuando usamos muchísimos rectángulos, todas terminan acercándose al mismo número: el área real. Compruébalo tú misma en el simulador.

Sumas de Riemann

Ponerle nombre y fórmula a la idea de los rectángulos.

El matemático alemán Bernhard Riemann (siglo XIX) escribió de forma ordenada esta idea de sumar rectángulos. Por eso, a esa suma se le llama suma de Riemann. Vamos a construir su fórmula pieza por pieza.

Pieza 1: el ancho de cada rectángulo (Δx)

Si el intervalo va de a a b y lo partimos en n pedazos iguales, cada pedazo mide:

Δx = b − an

El símbolo Δx (se lee "delta x") significa "un pedacito de x". Es como partir una tabla de 1 metro en 4 partes iguales: cada una mide 1/4 = 0.25 m.

Pieza 2: dónde medir la altura (xᵢ)

Usando el extremo derecho, los puntos donde medimos son:

xᵢ = a + i · Δx,    con i = 1, 2, 3, …, n

Es decir: partimos de a y avanzamos i pasos de tamaño Δx.

Pieza 3: el área de un rectángulo

Área del rectángulo número i = f(xᵢ) · Δx   =   altura × base

Juntando todo: la suma de Riemann

Sₙ = nΣi = 1 f(xᵢ) · Δx

Se lee: "sumar las áreas de los n rectángulos".

Ejemplo 1: f(x) = x² en [0, 1] con 4 rectángulos

  1. Identificamos los datos: a = 0, b = 1, n = 4.
  2. Calculamos el ancho:
    Δx = 1 − 04 = 14 = 0.25
  3. Calculamos los puntos (extremo derecho), xᵢ = 0 + i · 0.25:
    x₁ = 0.25,   x₂ = 0.5,   x₃ = 0.75,   x₄ = 1
  4. Evaluamos la función en cada punto (elevamos al cuadrado):
    f(0.25) = 0.0625,   f(0.5) = 0.25,   f(0.75) = 0.5625,   f(1) = 1
  5. Sumamos las alturas:
    0.0625 + 0.25 + 0.5625 + 1 = 1.875
  6. Como todos tienen la misma base, multiplicamos la suma de alturas por Δx:
    S₄ = 1.875 × 0.25 = 0.46875

Si repites el proceso con el extremo izquierdo (x = 0, 0.25, 0.5, 0.75), obtienes (0 + 0.0625 + 0.25 + 0.5625) × 0.25 = 0.21875. El área real queda entre esos dos valores. ¡Ya la tenemos "acorralada"!

Ejemplo 2: el mismo cálculo, pero con n rectángulos

Ahora hacemos lo mismo sin decir cuántos rectángulos son. Esto nos permitirá ver qué pasa cuando n crece muchísimo.

  1. El ancho:
    Δx = 1 − 0n = 1n
  2. Los puntos:
    xᵢ = 0 + i · 1n = in
  3. La altura en cada punto (elevamos al cuadrado numerador y denominador):
    f(xᵢ) = (in)² = i²n²
  4. Armamos la suma de Riemann:
    Sₙ = nΣi=1 i²n² · 1n = nΣi=1 i²n³
  5. n³ no cambia mientras i avanza, así que sale de la suma como constante:
    Sₙ = 1n³ · nΣi=1 i²
  6. Usamos la fórmula de la suma de cuadrados (está en Conocimientos previos):
    Sₙ = 1n³ · n(n + 1)(2n + 1)6
  7. Simplificamos una n de arriba con una de abajo (n³ ÷ n = n²):
    Sₙ = (n + 1)(2n + 1)6n²
  8. Multiplicamos los paréntesis: (n + 1)(2n + 1) = 2n² + n + 2n + 1 = 2n² + 3n + 1
    Sₙ = 2n² + 3n + 16n²
  9. Comprobamos con n = 4: 2(16) + 12 + 16(16) = 4596 = 0.46875. ¡Igual que en el Ejemplo 1! ✔

El paso final: rectángulos infinitamente delgados

Ahora hacemos que la cantidad de rectángulos crezca sin límite (n → ∞). Esto ya lo resolvimos en Conocimientos previos:

  1. Planteamos el límite:
    limn→∞ 2n² + 3n + 16n²
  2. Separamos y simplificamos:
    limn→∞ ( 13 + 12n + 16n² )
  3. Los términos con n abajo se van a cero:
    = 13 ≈ 0.3333
✔ Conclusión
El área exacta bajo y = x² entre 0 y 1 es 1/3. Ya no es una aproximación: el límite eliminó el error por completo.

Nace la integral definida

Lo que acabamos de hacer tiene nombre propio.

Al límite de las sumas de Riemann, cuando los rectángulos se hacen infinitamente delgados, se le llama integral definida:

∫ba f(x) dx = limn→∞ nΣi = 1 f(xᵢ) Δx

¿Qué significa cada símbolo?

SímboloNombreQué representa
∫Signo de integralEs una "S" alargada, de Suma. Reemplaza a la Σ.
a, bLímites de integraciónDónde empieza (a) y dónde termina (b) la región.
f(x)IntegrandoLa altura de cada rectángulo.
dxDiferencialEl ancho infinitamente pequeño: es lo que queda de Δx cuando n → ∞.

Fíjate en el paralelo: Σ → ∫  y  Δx → dx. La notación misma te recuerda que una integral es una suma de rectángulos infinitamente delgados.

Entonces, el resultado de la sección anterior se escribe así:

∫10 x² dx = 13
💡 Analogía: una alcancía
f(x) es cuánto dinero metes cada día y dx es cada día. La integral es todo lo que se acumuló en la alcancía entre el día a y el día b.

Área con signo: cuando la curva va por debajo del eje

Si la función es negativa, la "altura" f(xᵢ) es un número negativo, así que el rectángulo aporta un valor negativo a la suma.

  • Partes arriba del eje x → suman.
  • Partes debajo del eje x → restan.

Por eso la integral de sen x de 0 a 2π da 0: la "colina" de arriba y el "valle" de abajo son del mismo tamaño y se cancelan. Pruébalo en el simulador.

💡 Analogía: la cuenta del banco
Los depósitos (arriba del eje) suman y los retiros (abajo del eje) restan. La integral te dice el saldo neto, no cuánto dinero movilizaste en total.
⚠ Ojo
Si te piden el área total (sin signo), debes calcular por separado las partes de arriba y de abajo, y sumar los valores positivos de cada una.

El atajo: Teorema Fundamental del Cálculo

Calcular límites de sumas cada vez es agotador. Por suerte, existe un atajo enorme.

Hacer sumas de Riemann para cada función sería larguísimo. Newton y Leibniz descubrieron que las integrales y las derivadas están conectadas: son operaciones inversas, como sumar y restar, o multiplicar y dividir.

La antiderivada (o primitiva)

Una antiderivada de f(x) es una función F(x) cuya derivada es f(x):

F′(x) = f(x)

Ejemplo: ¿qué función, al derivarla, da 2x? Respuesta: x², porque (x²)′ = 2x.

Pero también x² + 5, x² − 7, x² + 100… ¡todas tienen derivada 2x! Porque la derivada de una constante es 0. Por eso escribimos:

∫ 2x dx = x² + C

Esta integral sin límites se llama integral indefinida, y la C representa "cualquier constante".

💡 Analogía: la constante C
Sabes que un tanque se llena a cierta velocidad, pero nadie te dijo cuánta agua tenía al inicio. Puedes describir cómo crece el agua, pero siempre te falta ese "valor inicial". Esa incógnita es la C.
💡 Analogía: rebobinar
Derivar es como ver un video hacia adelante (de la distancia obtengo la velocidad). Integrar es rebobinarlo (de la velocidad recupero la distancia).

El teorema (versión práctica)

Si F es una antiderivada de f, entonces:

∫ba f(x) dx = F(b) − F(a)

Es decir: para calcular el área ya no necesitamos rectángulos. Solo buscamos la antiderivada, la evaluamos en b, la evaluamos en a y restamos. Se suele escribir con corchetes: [F(x)]ba.

💡 Analogía: el odómetro
Para saber cuántos kilómetros recorriste entre la 1 p. m. y las 3 p. m., no necesitas sumar la velocidad de cada segundo: lees el odómetro a las 3, le restas lo que marcaba a la 1, y listo. El odómetro es la antiderivada F.

Comprobemos con el ejemplo de la sección 4

  1. Queremos ∫10 x² dx.
  2. Buscamos una antiderivada de x². Como (x³3)′ = 3x²3 = x², tomamos:
    F(x) = x³3
  3. Evaluamos en el límite de arriba (b = 1):
    F(1) = 1³3 = 13
  4. Evaluamos en el límite de abajo (a = 0):
    F(0) = 0³3 = 0
  5. Restamos:
    F(1) − F(0) = 13 − 0 = 13
✔ ¡Mismo resultado!
Con rectángulos y límites tardamos 9 pasos; con el teorema, 4. Y ambos caminos llegan a 1/3.
⚠ ¿Y la C?
En una integral definida la C se cancela sola: (F(b) + C) − (F(a) + C) = F(b) − F(a). Por eso no se escribe.

Propiedades de las integrales

Reglas que facilitan el trabajo. Todas tienen sentido si piensas en "sumar rectángulos".

1. Constante por una función
∫ba k · f(x) dx = k · ∫ba f(x) dx

Por qué: si todos los rectángulos se hacen k veces más altos, el área total también es k veces más grande.

Ejemplo: ∫10 6x² dx = 6 · ∫10 x² dx = 6 · 13 = 2

2. Suma y resta
∫ba [f(x) ± g(x)] dx = ∫ba f(x) dx ± ∫ba g(x) dx

Por qué: si cada rectángulo tiene altura "f más g", podemos sumar por separado la parte de f y la parte de g.

Analogía: en una factura, puedes sumar primero todas las frutas y luego todas las verduras; el total es el mismo.

⚠ Importante
Esto no funciona con multiplicación ni división: ∫ f · g dx ≠ (∫ f dx)(∫ g dx). Por eso primero hay que desarrollar o simplificar.
3. Integral de una constante
∫ba k dx = k · (b − a)

Por qué: la gráfica de y = k es una línea horizontal; el área debajo es un rectángulo de altura k y base b − a.

Ejemplo: ∫52 4 dx = 4 · (5 − 2) = 4 · 3 = 12

4. Intervalo de ancho cero
∫aa f(x) dx = 0

Por qué: si empiezas y terminas en el mismo punto, la base mide 0, y cualquier altura por 0 da 0. Es como recorrer 0 minutos: no avanzas nada.

5. Invertir los límites cambia el signo
∫ab f(x) dx = − ∫ba f(x) dx

Por qué: con el teorema, F(a) − F(b) = −(F(b) − F(a)). Es como caminar de regreso: recorres la misma distancia, pero en sentido contrario.

Ejemplo: ∫01 x² dx = −13

6. Unir intervalos (aditividad)
∫ba f(x) dx + ∫cb f(x) dx = ∫ca f(x) dx

Por qué: si pintas la pared en dos partes, el total de pintura es la suma de ambas partes.

Ejemplo paso a paso con f(x) = x² y F(x) = x³3:

  1. De 0 a 1:
    F(1) − F(0) = 13 − 0 = 13
  2. De 1 a 2:
    F(2) − F(1) = 83 − 13 = 73
  3. Sumamos las dos partes:
    13 + 73 = 83
  4. Directamente de 0 a 2:
    F(2) − F(0) = 83 − 0 = 83   ✔ ¡Igual!
7. Comparación (signo de la integral)

Si f(x) ≥ 0 en todo [a, b], entonces ∫ba f(x) dx ≥ 0.

Y si f(x) ≥ g(x) en todo el intervalo, entonces ∫ba f(x) dx ≥ ∫ba g(x) dx.

Por qué: si una curva siempre está más arriba que otra, tiene más área debajo. Sirve para revisar si un resultado "tiene sentido".

Súmale 1 al exponente y divide entre el nuevo exponente. Es lo contrario de derivar (allá se baja el exponente y se le resta 1).
⚠ ¿Por qué n ≠ −1?
Si n = −1, el nuevo exponente sería −1 + 1 = 0 y tendríamos que dividir entre 0. Por eso x⁻¹ = 1x tiene su propia regla: ln|x|.

Ejemplo A: un polinomio

∫ (3x² + 2x − 5) dx

  1. Separamos en tres integrales (propiedad de suma y resta):
    ∫ 3x² dx + ∫ 2x dx − ∫ 5 dx
  2. Sacamos las constantes (propiedad 1):
    3∫ x² dx + 2∫ x dx − ∫ 5 dx
  3. Aplicamos la regla de la potencia. Recuerda que x = x¹:
    3 · x³3 + 2 · x²2 − 5x + C
  4. Simplificamos (3 entre 3 da 1, y 2 entre 2 da 1):
    x³ + x² − 5x + C
  5. Verificamos derivando:
    (x³ + x² − 5x + C)′ = 3x² + 2x − 5   ✔

Ejemplo B: una raíz

∫ √x dx

  1. Escribimos la raíz como potencia:
    ∫ x1/2 dx
  2. Le sumamos 1 al exponente: 12 + 1 = 12 + 22 = 32
    x3/23/2 + C
  3. Dividir entre 3/2 es lo mismo que multiplicar por su recíproco 2/3:
    23 x3/2 + C
  4. Verificamos: (23 x3/2)′ = 23 · 32 x1/2 = x1/2 = √x ✔

Ejemplo C: una potencia en el denominador

∫ 1x³ dx

  1. Subimos la potencia con exponente negativo:
    ∫ x⁻³ dx
  2. Sumamos 1 al exponente: −3 + 1 = −2
    x⁻²−2 + C
  3. Regresamos la potencia negativa al denominador para que se vea más ordenado:
    −12x² + C

Ejemplo D: desarrollar antes de integrar

∫ (x + 1)² dx

  1. No hay regla directa para un paréntesis al cuadrado, así que desarrollamos el binomio:
    (x + 1)² = x² + 2x + 1
  2. Integramos término por término:
    ∫ x² dx + ∫ 2x dx + ∫ 1 dx
  3. Aplicamos las reglas:
    x³3 + 2 · x²2 + x + C
  4. Simplificamos:
    x³3 + x² + x + C

Ejemplo E: factorizar antes de integrar

∫ x² − 1x − 1 dx

  1. Reconocemos una diferencia de cuadrados arriba:
    x² − 1 = (x − 1)(x + 1)
  2. Reemplazamos en la fracción:
    (x − 1)(x + 1)x − 1
  3. Cancelamos el factor (x − 1) que está arriba y abajo (válido cuando x ≠ 1):
    x + 1
  4. Integramos:
    ∫ (x + 1) dx = x²2 + x + C

Ejemplo F: dividir término por término

∫ x³ + 2xx dx

  1. Dividimos cada término de arriba entre x:
    x³x + 2xx = x² + 2
  2. Integramos:
    ∫ (x² + 2) dx = x³3 + 2x + C

Ejemplo G: funciones trigonométricas y exponenciales

∫ (4 cos x − 3eˣ) dx

  1. Separamos y sacamos constantes:
    4∫ cos x dx − 3∫ eˣ dx
  2. Usamos la tabla (∫ cos x dx = sen x y ∫ eˣ dx = eˣ):
    4 sen x − 3eˣ + C

Ejemplo H: una integral definida completa

∫31 (2x + 1) dx

  1. Buscamos la antiderivada: ∫ 2x dx = x² y ∫ 1 dx = x:
    F(x) = x² + x
  2. La escribimos con los límites:
    [ x² + x ]31
  3. Evaluamos en 3:
    F(3) = 3² + 3 = 9 + 3 = 12
  4. Evaluamos en 1:
    F(1) = 1² + 1 = 1 + 1 = 2
  5. Restamos:
    12 − 2 = 10
✔ Comprobación con geometría
La gráfica de 2x + 1 es una recta, así que el área bajo ella entre 1 y 3 es un trapecio. Alturas: f(1) = 3 y f(3) = 7; ancho: 3 − 1 = 2. Área = 3 + 72 × 2 = 5 × 2 = 10. ✔ ¡Coincide! (Puedes verlo también en el simulador con f(x) = 2x + 1.)

Ver solución
  1. Factorizamos el trinomio (dos números que multiplicados den 6 y sumados den 5: 2 y 3):
    x² + 5x + 6 = (x + 2)(x + 3)
  2. Cancelamos (x + 2):
    (x + 2)(x + 3)x + 2 = x + 3
  3. Integramos:
    x²2 + 3x + C

4. ∫20 (x² + 1) dx

Ver solución
  1. Antiderivada:
    F(x) = x³3 + x
  2. Evaluamos en 2:
    F(2) = 83 + 2 = 83 + 63 = 143
  3. Evaluamos en 0:
    F(0) = 0 + 0 = 0
  4. Restamos:
    143 − 0 = 143 ≈ 4.667

5. ∫π0 sen x dx

Ver solución
  1. Antiderivada (de la tabla):
    F(x) = −cos x
  2. Evaluamos en π: cos π = −1
    F(π) = −(−1) = 1
  3. Evaluamos en 0: cos 0 = 1
    F(0) = −1
  4. Restamos:
    1 − (−1) = 1 + 1 = 2

Una sola "colina" de la función seno tiene área exactamente 2.
